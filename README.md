# DreamHome

A real-estate themed responsive website focused on property discovery and listing presentation. The page includes a navigation header, property-focused hero section, calls to action, and supporting content.

## Tech Stack

- HTML5
- CSS3
- Responsive Web Design

## Highlights

- Real-estate focused hero section
- Property navigation and calls to action
- Responsive layout
- Custom visual styling
- Structured content sections

## Getting Started

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/mdjihad-dev/DreamHome.git
cd DreamHome
```

## Project Focus

The project focuses on responsive frontend layout, typography, spacing, and building a polished property-oriented landing page with semantic HTML and CSS.
